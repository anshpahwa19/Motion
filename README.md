## Story
1. **The Fear Never Sleeps** — 2:17 AM, headlines about AI, the fear flashes.
2. **Another Day, Another Fear** — the alarm at 7:30, sitting on the bed edge, present at his desk but absent.
3. **The Machine That Never Stops** — an AI tool generates 24 screens in 9.8 s; doubt.
4. **The Human Factor** — a usability test with Mr. Rao, 62, who gets lost in the AI-generated banking app.
5. **A Different Way Forward** — Arjun brings the research into the AI tool; Mr. Rao pays in 38 seconds.
6. **Tomorrow Is Another Day** — another AI headline, a calm smile, lamp off, sleep.

# THE LAST LOGIN — Scene 1: *The Fear Never Sleeps*

An animated short about Arjun, a 28-year-old UX designer who can't sleep because
he's afraid AI will take his job. This repository has **Scene 1 only**: the
finished film plus the complete, editable production it was made from, so later
scenes can reuse the same character, set, look and pipeline.

| | |
|---|---|
| **Film** | `output/THE_LAST_LOGIN_Scene01.mp4`: 1920×1080, 24 fps, H.264 + AAC stereo, 31.0 s (26.5 s of scene + 4.5 s title card) |
| **Production file** | `source/scene01_the_fear_never_sleeps.blend` (Blender 5.0): scenes `Bedroom` and `Office` |
| **Everything else** | `project/`: the Python pipeline that builds the file, the phone UI, all the audio and the post |

Every asset in the film (the character, both sets, every texture, the phone UI,
the music, the sound effects and the compositing) is generated by code in
`project/`. There are no stock or third-party art assets. The voices come from
the open Kokoro-82M TTS model (Apache-2.0).

## 2. The character: ARJUN (reusable)

The model is built in `project/blender/character.py` and its `char_*.py` helpers.

* **Sculpt:** signed-distance-field anatomy (cranium, brow, cheekbones, nose,
  lips with a cupid's bow, ears, jaw), meshed with marching cubes. Head scale ×1.06 for stylisation.
* **Skin:** random-walk subsurface scattering, painted skin tone (warm cheeks,
  nose and ears, darker under the eyes for **dark circles**, lip colour),
  procedural **stubble** and pore bump.
* **Eyes:** a textured iris (fibres, collarette, limbal ring), a cornea layer
  for specular highlights, and separate upper and lower **eyelid shells** with
  lash-line tint and strand **eyelashes**.
* **Hair:** a dark, slightly messy cut made of about 22,000 groomed and clumped
  Cycles hair strands over a scalp cap. Brows are strand hair too.
* **Body:** arms and hands (thumb plus 4 fingers, 3 joints each) and a
  heather-teal home T-shirt with a collar, sleeves and wrinkles.
* **Rig** (`ARJ_Rig`): pelvis, spine, chest, a `breath` bone, neck and head.
  Each arm has IK with a pole target, and the hand follows its IK empty's
  rotation. 30 finger bones. Face controls are `eye.*` (gaze), `lid_up.*` and
  `lid_lo.*` (blinks), and `brow.*` (worry and raise). The skin weights are
  computed from the SDF parts themselves, so joints blend where the shapes blend.

Controls (pose bones unless noted):

| Control | Use |
|---|---|
| `head`, `neck`, `chest`, `spine` | FK rotation |
| `eye.L/R` | X = look up/down, Z = look left/right |
| `lid_up.*` | X rotation: −46° closed, −7° tired rest, 0 open |
| `lid_lo.*` | X rotation: +9° closed |
| `brow.*` | Y rotation tilts the brow (worry); location Y raises it |
| `f_<finger>.0n.*` | X rotation = curl |
| `breath` | Y scale = chest expansion |
| `IK_hand.L/R` (empty) | wrist position + hand orientation |
| `Pole_elbow.L/R` (empty) | elbow direction |

To reuse him in another scene, call `character.build_arjun(collection)` in a
new build script, or append the `CH_Arjun` collection from the `.blend`.

## 3. The look

* **Renderer:** Cycles path tracing at 1920×1080, with OIDN denoising
  (albedo + normal passes), motion blur and physical depth of field. Colour
  management is AgX, Medium High Contrast.
* **Lighting:** cool moonlight through the window grill (the bars cast stripes
  across the bed and his body), a warm city glow, a soft moon-bounce fill, the
  red LED clock with a glow light, and the phone screen as a real area light
  that switches on and off with the UI.
* **Post** (`project/post/composite.py`):
  * Night grade, highlight bloom, vignette and subtle chromatic aberration.
  * In the eye close-up, the world progressively darkens and blurs.
  * The fear flashes are graded near-monochrome and cold, with white-flash
    cuts, shake, RGB split and edge blur.
  * Fades and the title card.
  * At encode time, ffmpeg adds a light temporal denoise and film grain.

## 4. Sound

All of it is synthesized and frame-locked to the timing file (`project/audio/`):

* **Voice-over:** made with `tts.py` (Kokoro-82M).
  * The narrator is a calm, deep male voice (a blend of the *onyx* and *michael* voices).
  * The inner voice is younger and closer (*liam*), with echo taps and reverb.
* **Score:** a modelled piano (inharmonic partials, 3 detuned strings, hammer
  noise, convolution reverb) playing a sparse D-minor progression. A low drone
  with a creeping semitone builds tension under the phone sequence. The ending
  chord and one emotional note sit under the title.
* **Sound design:**
  * Bedroom: room tone, distant city, the fan, the ticking clock.
  * Phone: notification chime and vibration, unlock, scroll, lock, the phone
    set down on wood, sheet rustles.
  * Fear flashes: heartbeat that speeds up, sub hits on every cut, laptop
    power-down, the ID card's flutter and clack, chair creak, light relays.
    This bus is run through saturation and a bit-crusher.
  * Waking up: a gasp and an exhale.
* **Mix:** music ducks under the voice-over, and the whole mix is
  loudness-normalised to −16 LUFS with −1.5 dBTP peaks at encode. Stems are in
  `project/assets/audio/` (FLAC).

## 5. Rebuilding and rendering

Requirements:

* Python 3.11 with `bpy==5.0.1`, `numpy`, `scipy` and `scikit-image`
  (`pip install bpy scikit-image scipy`)
* `pillow`
* `ffmpeg`
* For the voices only: `kokoro-onnx` and `soundfile`, plus the Kokoro v1.0
  model files from the kokoro-onnx GitHub releases

```bash
cd project/blender
```

```bash
python build_scene01.py -- --lod 1.0
```

This generates the phone UI and textures if they're missing, builds
`source/scene01_the_fear_never_sleeps.blend` (about 5 minutes) and can be
re-run any time. Render the three frame ranges:

```bash
python render_frames.py -- ../../source/scene01_the_fear_never_sleeps.blend ../../renders/raw Bedroom 1 420 --skip-existing
```

```bash
python render_frames.py -- ../../source/scene01_the_fear_never_sleeps.blend ../../renders/raw Office 421 516 --skip-existing
```

```bash
python render_frames.py -- ../../source/scene01_the_fear_never_sleeps.blend ../../renders/raw Bedroom 517 636 --skip-existing
```

Then the audio, the post and the encode:

```bash
cd ../audio && python tts.py kokoro-v1.0.onnx voices-v1.0.bin && python sound.py
```

```bash
cd ../post && python composite.py ../../renders/raw ../../renders/final
```

```bash
./encode.sh ../../renders/final ../assets/audio/scene01_mix.wav ../../output/THE_LAST_LOGIN_Scene01.mp4
```

`render_frames.py` takes `--res 25 --spp 4 --no-mblur` for quick previews and
`--frames a,b,c` for spot checks. If you open the `.blend` in the Blender app,
the camera cuts are timeline markers in each scene. The phone-screen image
sequence lives in `project/assets/phone_ui/`; it isn't committed, so run
`python project/ui/phone_ui.py` once.
